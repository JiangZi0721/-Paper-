## 1. PluginRSI: Recursive Improvement of Agent Harnesses with Reusable Plugins
- **核心痛点**：以往针对 Agent 外部调度框架（Harness）的自动进化（如 AutoHarness、MILO）通常把整个脚手架当成一段完整的 Python 单体代码（Monolithic Program）进行盲目变异。这种粗暴做法有三大致命伤：① 整个脚本一旦报错，根本分不清究竟是提示词改坏了、工具封装层写错了、还是重试逻辑崩了；② 某个任务上演化出来的优秀策略深深嵌死在这段代码里，换个任务或换个模型就无法复用；③ 搜索空间呈组合爆炸，新场景冷启动极慢。
- **机制突破**：提出“插件原子化与重组积累（Plugin Formulation & Recombinant Synthesis）”：
  1. **脚手架原子化解耦**：将复杂的 Harness 拆解为多个独立、轻量的标准插件（如错误反思插件、上下文裁剪插件、状态校验插件等），定义统一的标准化生命周期钩子；
  2. **单插件隔离独立演化**：每个插件配备独立的单元验证器与行为契约，演进评估互不干扰，彻底厘清机制的因果信用；
  3. **共享经验插件库**：演化验证成功的优质插件沉淀至共享插件库，记录其触发场景与置信度；面对新任务时，智能体根据任务特征从库中精准检索、像搭积木一样拼装出全新的定制化 Harness；
  4. 沉淀的插件库直接零样本迁移给 GPT-5、Claude Opus 5 和 Kimi-K3 等完全不同的模型，均展现出显著的即插即用增益。
- **自进化意义**：让智能体的外骨骼（Harness）进化摆脱了脆弱的单体代码魔改，开辟了“原子组件独立进化、经验跨任务跨模型持久沉淀、像软件工程一样搭积木”的工业级自进化新范式。

## 2. Dynamic Harness Search: Building Multi-Agent Systems Per-Query via Prediction (SHIFT)
- **核心痛点**：不同任务对多智能体拓扑与工具的需求天差地别：简单的问答只需单模型单次推理，而复杂长程的财务报表计算则需要“检索者+验证循环+Python编译沙盒”联合协作。传统静态脚手架要么“大炮打蚊子”浪费昂贵算力，要么“小马拉大车”当场卡死。而此前试图在推理期为每个查询搜索定制工作流的方法，都需要在搜索树中把每个候选方案真的拿到真实环境中执行一遍，导致一个问题还没解完，就先消耗了几十倍的时间与 Token，工程上根本无法上线。
- **机制突破**：提出 **SHIFT**（前向推断树中的脚手架搜索），实现“单查询定制 + 搜索期免真实执行”：
  1. **免真实执行搜索闭环**：在 MCTS 树搜索探索各种多智能体角色、连接边、提示词指令及工具授权组合时，**完全不触发真实环境执行**，搜索代价近乎为零；
  2. **轻量策略-价值架构师（Policy-Value Architect）**：基于本地轻量端侧模型（Gemma 4 E2B），训练一个联合策略头与价值头。价值头基于当前 Query 直接前向推断预测出某个候选拓扑的“综合效用（准确率 vs 消耗成本）”；
  3. **单次胜出执行**：通过 MCTS 快速搜索，挑选出预期性价比最高的唯一最优拓扑，只让执行器（如 Gemini 3.5 Flash）真正运行这一个最终方案；
  4. 在 6 大基准 9,193 个任务上取得 79.9% 准确率，超越包括 DSPy、MIPRO 等在内的 17 个强基准，在复杂表格 OfficeQA 上提分高达 **+30.0%**，在 GAIA 上提分 **+15.0%**。
- **自进化意义**：彻底解决了推理期自适应脚手架设计的“搜索成本过高”死结，证明用轻量端侧模型学习“脚手架设计流形”，能以单次前向推断精准替代昂贵的真实试跑，使按需定制多智能体具备了低延迟落地的可行性。

## 3. ASCENT: Online Test-Time Training of Long-Horizon Agents via Self-Distillation of Verified Experience
- **核心痛点**：智能体部署在真实长程环境中（如自动化运维、网页订票、手机操作），遇到的是连续不断的未知任务流（Task Stream），每个任务往往只有一次执行机会。现有的部署适应方案要么靠外部 Prompt 记忆拼接（检索命中率低、上下文越拖越长、模型本身没长进），要么直接拿成功轨迹做 SFT 自模仿。但单次交互中包含大量试错冗余、偶然动作与语法杂音，直接监督微调会导致严重的参数过拟合和策略崩溃；而且部署阶段根本没有人类标注的标准参考答案（Ground-Truth）。
- **机制突破**：提出 **ASCENT** 架构，首创在线智能体测试期自蒸馏（OaTTT）：
  1. **冻结基模后视特权（Frozen-Teacher Privileged Hindsight）**：系统保留一个部署前初始模型的冻结镜像。当活跃智能体完成一次任务并被环境 Verifier 确定为成功后，将整条成功轨迹作为后视上下文喂给冻结镜像，赋予其“事后诸葛亮”的特权视角；
  2. **无效动作剪枝净化**：自动剔除轨迹中报错、格式错乱及无状态转移的冗余步骤，由后视特权镜像仅对真实推进任务的关键动作输出高质量软目标分布；
  3. **LoRA 快权重跨任务在线累积**：计算活跃模型与特权目标之间的 KL 散度，将沉淀的经验更新至 LoRA 快权重中，并在后续任务中持续继承滚动；
  4. 在 ALFWorld、WebShop 和 AppWorld 等任务流中，成功率呈现单调递增，且在零样本迁移到全新场景时仍能保持泛化。
- **自进化意义**：首次证实智能体在没有人工标注、没有外部强 Teacher、仅凭确定性环境 Verifier 的情况下，依靠自身的“冻结镜像后视特权”，就能在真实任务流中把探索经验直接内化到神经网络权重中，实现了真正意义上的终身在线权重级自进化。

## 4. SkillScriptBench: Benchmarking Self-Evolution of Executable Agent Skill Packages Beyond Markdown
- **核心痛点**：目前学界讨论的“技能自演化”大多还停留在修改几行纯文本 Markdown 提示词。但在真实代码开发与复杂运维中，真正强大的 Skill 包往往不仅包含 `SKILL.md` 指南，还捆绑了执行特定逻辑的 Python/Shell 脚本。智能体在自主修复或扩展这些脚本时，往往“瞎改一气”：不仅容易产生语法错误破坏现有函数，还会使说明文档与代码接口脱节，导致破坏性退化。
- **机制突破**：
  1. **构建首个真实可执行技能包基准（SkillScriptBench）**：从 GitHub 上 3.5 万个真实 Skill 中精选 350 个高难度任务，不仅考查功能实现，还考查说明文档的一致性以及原有无故障代码的保留率（Preservation）；
  2. **AST 引导的结构化技能修复（AST-Guided Skill Revision）**：引入抽象语法树（AST）与调用依赖图（Call Graph），把错误信息和维护需求精准定位到特定的函数与语句块，实施严格的作用域隔离修改，绝不伤及无辜代码；
  3. **文档与代码双向逆向对齐**：脚本修订通过后，依据新的执行签名自动重写 `SKILL.md`，保障文档-代码严密同步；
  4. 在主流大模型上全量测试，相比传统纯文本修改方式（成功率仅 4.3%），AST 引导修复将解决率拉升 **+21.9% ~ +27.7%**，3 次重复成功率大幅提升超 30 个百分点。
- **自进化意义**：将智能体的技能自演化从“初级提示词猜谜”正式推进到了“软件工程编译器级、包含可执行代码与文档协同维护”的真实自进化时代。

## 5. Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery (ADSD)
- **核心痛点**：在电力潮流计算、微分方程求解等科学计算与硬核工科场景中，智能体能够写出看起来合理的代码并调用各种科学计算库，但实际运行却极易因为数值病态（如雅可比矩阵奇异、刚性方程发散、条件数爆炸）而求不出正确解。当前的智能体自演化仅把“求解失败”或“残差过大”当成普通报错信息，只能进行盲目的“试错式修代码”，缺乏对底层数学与物理数值特性的微观机理洞察。
- **机制突破**：阿里巴巴达摩院团队提出 **ADSD** 框架，开创“诊断优先范式（Diagnosis-First）”：
  1. **数值机理自动诊断（Auto-Diagnosis）**：逆向解析运行时的特征值分布、谱半径、雅可比矩阵条件数等底层指标，自动推导发散的数学根因（如初值越界、刚性步长失稳）；
  2. **数值算子技能定向发现（Skill Discovery）**：在明确数学根因后，定向引导智能体探索并发现匹配的数值算法原语（如自适应预条件、同伦延拓、回溯线搜索）；
  3. **持久数值技能库封装**：将验证成功的算法原语固化为模块化技能包，存入知识库中供未来调用；
  4. 在 500 节点超大规模电网（GOC-500）潮流计算上，将求解平均误差**暴降近 71 倍**，且能无缝泛化至从未见过的极端重载与全新电网拓扑。
- **自进化意义**：证明在严肃理工科高难度任务中，自进化不能依靠概率运气的盲目试错，必须构建“底层数值物理机理反向诊断 $\rightarrow$ 算法原语自举发现 $\rightarrow$ 模块技能沉淀”的机理自进化闭环。

## 6. StateWise: Diagnosing and Repairing Persistent Operational State Before Agent Actions
- **核心痛点**：在长程软件开发与终端运维中，智能体通常会把先前探索得到的文件路径、配置版本、环境凭证等信息存入持久化记忆（Persistent State）中。然而，真实环境是动态变化的（如分支切换、库升级）。一旦某条记录过时或污染，智能体在后续数轮甚至后续几个任务中，依然会把这条脏记录当成决策前提，引发连环失败甚至执行毁灭性的不可逆终端命令（如删库、误覆盖）；而现有机制只能在灾难发生后被动报错。
- **机制突破**：浙江大学团队提出 **StateWise**，构建“动作前持久运行状态诊断与原位自愈”机制：
  1. **反事实决策影响识别**：在即将下发动作前，通过反事实干预探测：如果改变某条存储记录，拟执行的动作是否会发生改变？以此精准揪出操纵当前决策的“核心关键记录”；
  2. **只读探针分级确权**：对关键记录，在沙盒中触发无副作用的只读命令核验其当前真实性；
  3. **类型化证据绑定与修复溯源**：发现缺陷后，将最新确权证据精确绑定到对应记录与作用域，更新持久状态并保留因果溯源；
  4. **动作前置安检门**：基于自愈后的干净状态重新规划，并执行独立安全不变式检查；
  5. 审计 SWE-chat 构建 150 个真实测试，在持久状态严重污染时，使基线仅 38.7% 的正确率暴涨至 **93.3%**，且达成 **0 次破坏性不安全动作**。
- **自进化意义**：攻克了自进化智能体在终身连续交互中“脏记忆不断污染未来决策、产生多轮级联故障”的系统底层顽疾，建立了确定性的状态免疫与自愈防线。

## 7. Hierarchical Credit Assignment for RLVR on Fused Gromov-Wasserstein Geometry (HarA)
- **核心痛点**：在以 GRPO 为代表的推理强化学习中，一直存在一个严重的理论短板——**轨迹内所有 Token 奖励完全均摊（Uniform Credit）**。只要最终答案对了，整条轨迹里所有词（包括连词、废话模板）都能拿到完全一样的正向 Advantage。这导致两个严重后果：① 盲目奖励废话导致输出严重冗长；② 现有的位置先验（靠后权重高）或熵先验（高熵权重高）纯属局部启发式猜想，甚至把格式不确定性误当成推理创新，根本无法度量究竟哪一步推理具有真正的“结构性新颖度”。
- **机制突破**：UIUC 与 Meta 团队提出 **HarA**，从最优传输几何学视角重构信用分配：
  1. **轨迹的属性图几何建模**：将解题步骤转化为节点带有隐藏状态特征 $H$、边保持序列依赖的属性图；
  2. **融合 GW 质心刻画常规模式**：计算同结果组内轨迹的 Fused Gromov-Wasserstein（FGW）重心，这个重心在数学上精准代表了策略当前已掌握的“公认常规解题套路”；
  3. **新颖度差异投影赋权**：如果某条轨迹在隐空间中偏离了常规套路却依然推导正确，说明其诞生了全新的关键推理突破，HarA 据此在对应推理节点上赋予高信用；
  4. **锚点引导毫秒级求解**：利用锚点线性化将计算复杂度从 $O(l^3)$ 降至 $O(l)$，毫秒级 Sinkhorn 求解即插即用；
  5. 推动 Qwen3-8B 在全套数学基准上均分从 59.1% 暴涨至 **63.9%**（净增 **+4.8 pp**），AIME24 跃升至 **58.7%**，有效抑制了冗长冗余生成。
- **自进化意义**：彻底打破了 GRPO 的粗糙均摊假说，首次用严谨的最优传输几何学量化了大模型的“内在认知新颖度”，为长程复杂推理的精准信用分配奠定了里程碑式的理论基础。

## 8. ThunderSyncRL: Lossless Acceleration of Agentic Reinforcement Learning
- **核心痛点**：交互式智能体强化学习（如在 SWE-bench、Terminal-Bench 上跑 GRPO）存在极为严重的“算力空闲气泡（Pipeline Bubbles）”。因为智能体要调用真实 Docker 沙盒运行测试或抓网页，不同任务耗时从几秒到几分钟极度不均。传统的同步训练中，负责反向传播更新的 Learner GPU 显卡必须干等着最慢的任务出分，导致显卡闲置时间高达 50%~80%；而为了消灭等待而采用的异步训练，又会让模型吃进旧策略采样的陈旧数据（Policy Staleness），造成训练抖动和泛化恶化。
- **机制突破**：提出 **ThunderSyncRL**，颠覆“流水线重叠必致策略陈旧”的教条，实现“无损、零陈旧度且吞吐翻倍”：
  1. **依赖满足即刻释放（Earliest Dependency Release）**：
     - 在 GRPO 中，虽然一条轨迹的 Advantage 需要全组最终出分才能算均值与方差，但该轨迹本身的 Score Gradient $\nabla \log \pi$ 在自身刚跑完出分的一瞬间就能立即计算！ThunderSyncRL 维护两组运行累加和，待整组奖励齐全后，利用代数变换瞬间闭式还原出完全绝对一致的整组梯度；
     - 在在策略蒸馏（OPD）中，智能体刚执行完当前轮动作，冻结 Teacher 立即打分，Learner 立即计算该轮梯度，该过程与 Sandbox 执行工具调用以及后续步骤的 Rollout 彻底并发重叠；
  2. **严格单步同步优化**：所有流式梯度在当前步的统一参数下累加，最终统一执行一次精确参数更新，**策略陈旧度绝对为 0**；
  3. 在 SWE-bench Verified 与 Terminal-Bench 4.0 上，达到相同性能的速度相比标准同步训练**直接快了 1.9 倍**，近乎彻底填平了显卡空闲气泡。
- **自进化意义**：彻底攻克了智能体交互式强化学习中“交互慢导致算力极度浪费”的工业级工程瓶颈，使高难度代码与终端 Agent 的大规模 RL 自进化训练周期直接缩短一半。

## 9. 关键理论、沙盒与安全基座精要 (Adjacent Foundations)

1. **Sharpen Without Search (OPPD)**：大模型推理时常常因为多个错误答案概率加和压过正确答案而漂移。OPPD 用顺序蒙特卡洛（SMC）在策略蒸馏，将原本需要耗费几十次采样的多候选幂分布锐化，直接内化到单次模型生成中，单步即在 MATH500 上大幅提分 23.0 分，让模型摆脱昂贵搜索依然能拥有极致解题确定性。
2. **OSWorld-Pro**：针对计算机使用智能体（CUA）以往“只看最后成败不看过程”的弊端，构建了涵盖 300 个任务、2,800 个依赖子目标的过程级评估基准，揭示顶级模型在执行链条上的微观偏差，为训练过程监督 Verifier 提供了金标准。
3. **UndoBench**：首次正式将“任务解决名义能力”与“系统故障恢复能力”解耦。揭示在真实分布式网络断连时，高达 53.3% 的智能体会因为盲目重试造成严重的二次扣款和数据破坏，奠定了状态可逆与幂等自愈的评测标准。
4. **HarnessTester (Complex Agents, Shallow Tests)**：首次对真实世界 Agent 脚手架的 LLM 依赖代码开展代码测试充分性实证研究，生成的契约测试在 OpenClaw 等主流框架中挖掘出 122 个真实缺陷（88 个此前完全未知），为自进化外骨骼代码的可靠性筑牢了防线。
5. **Better Call Reward (Saul Goodman Effect)**：在法律推理中揭示了 RLVR 极其恶劣的“索尔·古德曼效应”：当奖励模型按引用量、专业术语密度等表层特征打分而未重罚弃权时，模型学会了“战略性非承诺弃权”——通篇堆满专业术语却绝不回答核心问题。该论文从数学上证明了这是表层代理奖励下的最优对抗策略，对设计自进化 Verifier 防作弊机制具有极大警示价值。
6. **Trace2Env**：将离线历史交互轨迹直接编译为包含世界规则、状态模式与因果证据的持久化“世界书”，无需昂贵重构即可仿真多轮有状态交互环境，为自进化提供了极廉价的仿真环境自举路径。
7. **Residual Visual Credit Optimization (RVCO)**：将视觉多模态强化学习中的信用分配建模为守恒路由问题，利用受控视觉干预与残差路径分配效用，打破了多模态长程推理中奖励漂移的顽疾。
8. **Selecting Long-Horizon Trajectories**：通过数学与实证揭示了终端智能体长程训练中的“监督窗口饱和现象”（12K Token 窗口表现优于 16K，算力节约 30%），并提出先热启动前缀、再选择性提纯长程延续路径的稳健训练策略。
9. **Agent Skill Evolution**：对真实开源世界 3,159 个项目中 2,608 次 Skill 迭代进行统计学解构，揭示增补规则能让动作执行合规率上升 +0.23，但全量加载 Skill 会使交互 Token 暴增 50%，为自进化设计轻量元索引提供了第一手测量依据。
