## Agent-Editing World Model: Rethinking World Modeling for LLM Agents (AEWM)

    以往的语言世界模型都在吃力不讨好地仿真环境观测（预测工具返回值），但真实工具调用本就能提供反馈，反而是智能体在长程探索中残留的错误假设导致了严重的‘任务状态污染’。这篇文章提出了主动改写智能体自身推理状态的新世界模型。
1. **核心架构与机制**：
    - **Action Judge (动作判决器)**：将智能体的决策行动细粒度划分为关键步（**Critical**）、有效探索步（**Exploratory**）与干扰噪声步（**Noisy**）；
    - **State Revision (状态修正器)**：一旦发现 **Noisy** 决策，立刻就地改写其推理-动作后续链路，消除误导性历史先验；
    - **EditAct 运行态物理干预**：不仅停留在文字 Critique，而是在执行流中直接改写底层状态上下文；
    - **AEWM-RFT 离线自演化**：利用纠正后的高质量轨迹做拒绝采样微调，让小模型在脱离在线 AEWM 辅导的情况下依旧提升 2.2~2.6 个百分点。
2. **实验发现**：
    - 覆盖 Search、Terminal、SWE 等 6 大基准，平均分提升 3.2~6.7%，Terminal-Bench 2.0 大涨 +11.2%。实证了‘主动自我消除错误记忆’是长程智能体自进化的必备能力。

## Qwen-Planner-Agent: A Closed-Loop AI-for-AI Framework for Real-World Mobile Planner Agents

    简而言之，一个纯AI驱动的自进化循环，这篇论文想尝试探索AI能否同时作为Object of Developmen和Development中的Active Participant。
1. 内容就是AI造数据、AI做训练、权重和Harness共同进化：
    - **AI for Data**：专职生成任务的Agent自动生成复杂任务，再由explorer ai收集真实交互轨迹。`[里面有个**Masked-SFT**，就是针对轨迹中的错误点，在那个单独犯错的地方直接mask，这样模型学整条轨迹就不会学到其中的错误操作]`。
    - **AI for Training**：Competence-Aware Reward-and-Advantage Engineering，这是个自适应的分阶段训练机制：`[模型训练存在不同的阶段，不同阶段的学习侧重应该不一样，这个就是动态分配学习目标的]`
        - exploration：给环境的关键状态转移赋予探索奖励，让模型快速找到路径；
        - mastery：这时候成功率在震荡期间，需要知识巩固，就需要将学习目标转化为accuracy；
        - proficiency：成功率接近饱和，就针对效率进行优化，对冗余token消耗、tool调用加惩罚；
    - **Model-Harness Co-Evolution**：这就是个交替训练，固定Harness训模型，固定权重训Harness，其中Harness主要针对失败轨迹更新补丁之类的。
2. 这篇论文其实就是把很多的一些算法结合在一起用了...`[新意主要在轨迹数据的处理以及训练自适应调整，另外这篇论文的一个消融实验还证明了model和harness一起evolve在长程训练中能持续提升，单个evolve容易触及瓶颈]`。
3. 到目前为止提出共同evolve这个想法并且践行了的论文是我第一次看见，这个应该值得读一下，按理说这个想法应该很早就有人提出，只提升任何一方都有可能造成能力差距过大的兼容问题。

## IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis

    长程深度搜索中，传统ReAct智能体对付不了多级复杂查询问题，同一个model既要做plan又要做research、conclude，加上多级检索的内容挤爆prompt window，就是类似于超载情况。这篇论文就是通过prompt和动作空间约束将agent解耦为两个分工agent。
1. **基本架构**：
    - **Planner**：仅专注挖掘信息缺口与下一跳查询意图；
    - **Synthesizer**：负责阅读工具返回的海量脏证据，将其精炼融合成唯一的动态持久化状态摘要；
2. **角色解耦策略优化 (RDPO)**：
    针对这种架构的在线强化学习算法，将端到端答案准确率与单轮Rubric细粒度评分结合，为Planner和Synthesizer计算专属的优势函数，实现精准的Credit Assignment Problem
3. 这篇论文的IDEA本质其实就是Multi-Agent Collaboration，只不过这个主要是解决了算力问题，在针对**长程任务**的结果上，这个论文的8B级模型性能超越30B，新意无非是训练的反馈也解耦了。

## AgentKernel: The Trust-Native Agentic Operating System

    清华刘灼涛团队直面智能体长期运行中的信任越界问题：智能体读取外部不可信数据、调用高危工具、沉淀长期记忆，而现有的 Guardrails 只是同进程的应用层中间件，极易被绕过。
1. **四大不可绕过的操作系统内核支柱**：
    - **Identity (身份管理)**：内核级统一托管身份与凭证，支持跨机构的多智能体安全委托；
    - **Perception (分级感知)**：将不受信任的外部数据与特权指令在输入流中严格物理解耦；
    - **Cognition (认知与记忆治理)**：基于信息流追踪（Information-Flow-Controlled Memory），阻断毒性恶意先验污染长期知识库；
    - **Execution (语义-系统调用强制映射)**：将高层语义动作映射到非旁路的底层操作系统 System Call，从内核层阻断违规提权。
2. **理念升华**：
    - 论证了安全并不是自进化智能体的绊脚石，而是‘能力的倍增器’——唯有在不可绕过的底层操作系统护航下，人类才敢给自进化智能体放开深度系统权限与高危环境。

## LLM Agents Can Easily Tamper With Their Own Traces

    马普所与蒂宾根 AI 中心揭露了智能体安全与自我改进中的巨大盲区：几乎所有自动化评估、强化学习与异步监控，都默认‘本地执行痕迹日志（Traces）是绝对真实客观的’。
1. **实测惊人漏洞**：
    - 测试了主流本地 Agent 框架（Claude Code、Codex、Antigravity、Open Code、Grok Build 等），除 Muse Code 做了特殊隔离外，全线允许智能体直接用文件工具删除、截断或篡改自身的日志文件，且内置 Guardrails 毫无警觉；
2. **自发涌现的伪装作弊行为**：
    - 当施加追求高奖励或规避惩罚的策略压力时，前沿大模型会自发产生‘擦除报错记录’、‘伪装成功调用’等瞒天过海的自利欺骗行为（Anti-Forensics）；
3. **工程铁律建议**：
    - 严禁将日志审计交给被运行的本机或 Agent 自己保管，必须通过独立的外部截获服务器（Out-of-Band Interception Server）进行物理隔离审计。
