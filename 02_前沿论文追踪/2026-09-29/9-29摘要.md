### 1. Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence (2609.35432)

    简单说，借鉴数字世界代码智能体（Coding Agents）的高泛化、可解释与自纠错能力，将其迁移至现实物理世界的具身机器人决策；
    以往的具身智能（VLA 与 WAM）将任务状态与执行过程隐式编码在庞大的动作序列中，导致一旦桌面布局微调、视角变动或指令稍微变化，策略就会彻底失败，且根本无法检视和反思。这篇论文提出了Physical Coding的自进化范式：借鉴数字代码智能体（Coding Agents）可调用工具、验证结果并自主修改代码的机制，将物理世界的任务状态与执行过程全部显式表达为可执行代码。

1. **物理世界代码化 Physical Coding**：
    - **Code as World**：将物理世界的空间位置、几何约束、目标属性与任务进度，全部维护成一份显式的 Python 世界状态对象；
    - **Code as Policy**：机器人的动作规划、前置条件检查、工具调用和异常恢复分支，全部以模块化的 Python 代码表达；
    - **只根据传感器反馈的几何/物理谓词（Predicate）做真值断言（Assertion）**
2. **物理部署**
    - 机器人的工控机Python后端对外暴露URAI接口。
    - **HexaAnything 具身智能体系统**：调用感知、规划与底层控制工具（包含 VLA/WAM），根据物理交互的外部反馈在运行时进行闭环自我修正；
3. **自进化**：验证通过的轨迹会自动转化为经验记忆与训练数据，推动智能体从工具与 Harness、模型权重、网络架构、乃至底层硬件与任务设计的全方位自我演进。
2. 这个就是将自进化智能体应用于具身智能，`[主要是将物理世界无法求导、无法梯度下降的机械与几何失败，巧妙地降维成了一份可以被编程智能体阅读、Debug、重构并用 git commit 持久化沉淀的Python工程代码。]`

### 2. RoboFoundry: System-as-Policy Evolution for Self-Learning Embodied Agents (2609.32862)

    现有的具身智能体往往将系统组件（记忆、上下文、技能库、动作接口）孤立调优，而没有把支撑整个智能体的“软件系统本身”视为一个统一策略。这篇论文首次提出“系统即策略自进化 (Self-Evolving System-as-Policy)”框架，让智能体在与物理环境的交互中，将经验转化为系统级的持久、经过校验的代码更新。

1. **核心设计**：
    - **双层演进界面**：
        - 上下文系统：管理活跃的内部运行上下文与文件系统持久化记忆；
        - 分层技能系统：自组织原子技能、可复用复合技能链以及基于失败条件的恢复策略；
    - **跨机体泛化解耦**：提出共享语义接口，将与机体无关的高级决策同特定机体的底层执行解耦，使得在机械臂 A 上演进出的高级能力能够无缝零样本迁移至四足机器人或双臂机器人 B；
    - **自进化闭环**：自动诊断决策和记忆管理中的能力短板，将执行轨迹转化为经过环境验证的系统更新，并将反复验证有效的模块提升至通用系统底层。

### 3. Beyond Timestamps: Decision-Aligned On-Policy Distillation for Long-Horizon Agents (2609.33391)
    在策略自蒸馏（OPSD）存在“决策-时间戳错位（Decision-Timestamp Mismatch）”的问题：在长程的复杂交互中，特权教师的指导可能发生在不同的时间步，或者学生的某一个功能性决策本身跨越了多个时间步，但是以往的就是硬编码教师的第t步去教导学生第t步，导致按单时间步对齐的信用分配完全混淆。

1. **Supervision Rectification**：
   - 论文将**思维链Thinking Traces**作为衡量两个不同时间戳的动作是否在做“同一件事”的依据，将其映射到决策空间，做相似性检查；
   - OPSD存在多条rollout轨迹，当前轨迹的动作还会在其他的轨迹中查找**同频（通过思维链）的教师**，Top-K个同频教师会根据自己的上下文对学生的采样动作进行评估(**对数似然**)；
   - 如果其余**多条轨迹里的老师**都在自己的上下文下给学生action打了极高的对数似然，就说明这个动作在多条轨迹都能适用，大幅增加advantage；如果得分低，即使最终成功也不给这个动作奖励；
   - 没有同频老师，那就只相信本轨迹的信号，不让其它老师指导。
2. **Hierarchical Credit Assignment**
    - 当一个决策正在连续执行时，它与兄弟轨迹的对齐分布是稳定的；一旦发生阶段性切换，对齐分布就会产生骤变；
    - 这篇论文通过语义状态转移变化（JS散度），把长交互轨迹切分为多段可变长度的的**高级决策跨度**；
    - 上面的高级决策跨度是根据轨迹优势自动加权分配预算的，在该跨度的预算内，再按具体的微观表现细分给内部的每一轮。
3. 这篇文章提出OPSD时间戳错位的问题并解决，但从结果来看只是超越baseline,其实提升不明显。

### 4. Surprising Success, Repeated Failure: Entropy-Guided Credit Assignment for Exploration in LLM Reasoning (2609.33781)

    大模型在策略强化学习（RLVR）中做细粒度信用分配往往需要额外的辅助模型或高昂的多次前向采样。而且对于失败轨迹直接惩罚，其中一些具有潜力的高不确定性分支就被消灭，探索空间被缩小。

1. **核心算法 (EAPO: Entropic Advantage Policy Optimization)**：
    - 这篇文章认为，熵衡量探索轨迹的探索性，高熵是突破性探索
    - **非对称奖惩引导**：
        - 成功轨迹中：对高熵（高度不确定却意外做对）的决策步给予极强的额外正向激励（Reward Surprising Success），加速锁定突破性探索；
        - 失败轨迹中：对低熵（模型非常自信却频频犯错）的决策步施加极其严厉的重罚（Correct Confident Failure）；而对高熵失败位置削弱惩罚，保留模型尝试不同分支的探索勇气；
    - **零额外算力开销**：完全利用现有 Rollout 产生的内部熵和 Advantage 符号进行重新加权分配，零额外标注或辅助模型。
2. **实验发现**：
    - 在多个数学与复杂推理任务中，全面提升收敛速度与解题覆盖率，生成的解题候选多样性显著增强。

### 5. Rethinking Training-Inference Mismatch in LLM Reinforcement Learning (2609.32444)

    当前大模型在策略 RL（如 RLVR、GRPO）的底层工业架构中普遍存在严重的“软硬件训练-推理引擎失配”：轨迹采样是由高并发的推理引擎（如 vLLM、SGLang）完成的，而参数反向传播是在分布式训练引擎（如 Megatron-LM、FSDP）上完成的。由于底层浮点精度截断、算子融合以及 KV 缓存优化的细微差异，两个引擎对同一个 Token 计算出的概率实际上存在系统性偏差，破坏了在策略重要性采样的无偏性。

1. **核心方案 (Calibrated Importance Sampling, CIS)**：
    - 刻画了 Log-odds 下的附加位移误差 $\varepsilon_t$，证明该误差在 Softmax 前的扰动独立于 Token 置信度；
    - 提出基于置信度的截断机制：置信度越高的 Token，重要性采样权重上限越严格收敛，消除无限方差；
2. **实证价值**：
    - 在 3 种 MoE 大模型和 5 个高难度数学推理基准上，全量刷新基线均分，为自进化底层分布式引擎消除了隐形崩溃隐患。

### 6. Program-Verified Self-Evolution for Vision-Language Models (2609.33855)

    在多模态领域，VLM自进化通常依赖模型从未标注图像中自问自答，但由于缺乏 Ground Truth，以往采用Majority Vote或 Model-as-Judge作伪标签，经人工评测其错误率挺高，严重的标签污染导致自进化在2~3轮后迅速性能饱和甚至退化。

1. **核心方法 (VQS: Verifiable QA Generation)**：
    - 核心就是把大模型降维成结构化特征解析器，将图像解析为结构化记录，计算交给规则性的代码；
        - 大模型按照schema将输入转化为结构化JSON记录；
        - Atomic Visual Checker将大图解为极小命题，逐一回答 Yes/No；
        - 确认100%正确的事实输入Program，输出答案；
        - 大模型把程序生成的模板语言，同义润色成自然的提问，而标准答案不准修改。
    - **门控**
        - 底层事实一旦有一处存疑，整道题直接丢弃；
        - 把图片拿掉，纯靠纯文本问大模型，如果大模型不看图光凭语言常识就能猜对，说明考的不是视觉能力，直接丢弃；
        - 只保留有梯度价值的适度难题，模型正确率或者错误率极高的都丢弃。
2. **自进化**
    整个过程中，大模型在无标注数据下的解析能力逐渐增强，求解器通过合并上一轮的权重，针对更难的题继续学习。

## 💡 旁支启发与环境沙盒 (Adjacent Inspirations)

### 1. Rolling-WAM: World Action Models with Rolling Imagination (2609.30247)
- **核心机制**：针对世界动作模型（WAM）联合视频与动作去噪延迟过高的致命痛点，提出基于滑动窗口的滚动去噪调度机制（Rolling Noise Schedule）；
- **实测成果**：去噪不必每次从头开始，实现 **4.5 倍重规划加速**，成功部署在宇树 Unitree G1 人形机器人实体上，为自进化智能体的低延迟世界模型推演提供了极佳解法。

### 2. CompoWorld: Compositional Environment Scaling for General Agents (2609.33665)
- **核心机制**：提出组合式环境扩展体系，通过状态空间、物理约束和目标图的组合自动合成高复杂度的新环境，为智能体提供了源源不断、难度渐进的自进化训练场。

### 3. Skill2Env: Capability-Oriented Environment Synthesis from Skills (2609.33772)
- **核心机制**：颠覆传统“先有环境再练技能”的被动逻辑，而是根据智能体当前欠缺的目标技能（Target Skills），**反向自动生成能最大化刺激该技能进化的物理交互环境**。

### 4. EmbodiedMemory-Bench (2609.28236)
- **核心价值**：首个系统针对长程具身智能体空间、情境与时序记忆能力的权威评测基准，全面揭示了当前智能体在长记忆检索上的断层缺陷。

### 5. BaRe-Mem: Bayesian Reliability Memory for Agent Consultation (2609.35551)
- **核心机制**：基于贝叶斯可靠度更新的智能体反思记忆机制，在多次协同咨询中动态校准不同专业领域智能体的置信度权重。

### 👑 【核心命门一 · 环境自生演化】 Skill2Env: Capability-Oriented Environment Synthesis from Skills (2609.33772)
* **本地 PDF**：[`2609.33772_Skill2Env_Capability-Oriented_Environment_Synthesis_Skills.pdf`](./2609.33772_Skill2Env_Capability-Oriented_Environment_Synthesis_Skills.pdf)
* **自进化第一性原理**：智能体不能在固定的人造静态题库里自嗨！真正的自进化必须依赖**“环境与智能体协同演化 (Agent-Environment Co-Evolution / POET 理念)”**。
* **核心机制突破**：
  1. **能力需求导向合成**：从智能体掌握的初始 Skill 出发，提炼可复用的**难度模式库（Difficulty Patterns）**（如指令歧义、隐蔽状态、噪声工具反馈、依赖前置条件）；

  3. **迭代任务硬化（Iterative Task Hardening）**：利用求解智能体的真实执行 Trace 找出过于简单的任务缺陷，持续动态加码难度，逼迫智能体自我突破；基于其自生成环境训练的智能体在多项通用 Agent 基准上全面刷新 SOTA。

### 👑 【核心命门二 · 无幻觉自举真值】 Program-Verified Self-Evolution for Vision-Language Models (2609.33855, VQS)
* **本地 PDF**：[`2609.33855_Program-Verified_Self-Evolution_Vision-Language_Models_VQS.pdf`](./2609.33855_Program-Verified_Self-Evolution_Vision-Language_Models_VQS.pdf)
* **自进化第一性原理**：脱离人类标注后，自问自答极易陷入**“幻觉毒化与自欺欺人”**（多数投票存在 24% 伪标签错误率，2 轮自演化即崩溃退化）。

  3. **单调持续演进**：将合成标签正确率硬生生拔高至 **94%**，成功在 Qwen3-VL 2B/4B/8B 上跑通了**连续 3 轮无衰退的单调自进化**。

### 👑 【核心命门三 · 自我工作流重写权限】 ControlScope: Workflow Revision and Reliability in LLM Agents (2609.34313)
* **本地 PDF**：[`2609.34313_ControlScope_Workflow_Revision_Reliability_LLM_Agents.pdf`](./2609.34313_ControlScope_Workflow_Revision_Reliability_LLM_Agents.pdf)
* **自进化第一性原理**：智能体在运行中发现自己策略有 bug 时，该在什么粒度上“修改自身”？粗暴地推倒重来会破坏原有规划，盲目微调又无法脱困。
* **核心机制突破**：
  1. **三级干预作用域形式化界定**：
     - `KEEP`：保持当前生成代码与规划不变；
     - `ARG`（参数微调）：仅修改下一个工具调用的数据参数（Argument Repair）；
     - `FULL`（全工作流重构）：从当前公共执行状态出发，推倒并彻底重构后续未完成的整个工作流。
  2. **嵌套权限与审查机制 (Nested Permissions)**：解耦智能体可用的修复操作与动作选择，精准界定智能体自我重构的**最小有效干预边界**，避免了自进化中的破坏性过度修改。
