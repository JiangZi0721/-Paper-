## 1. EVISKILL: Grounding Skill Evolution in Replayable Evidence
- **核心痛点**：目前智能体在外部维护可复用技能库（如操作指南、代码经验）时，存在两大硬伤：① **死记硬背不记因果**：智能体只记录了“技能规则修改了什么”，却丢失了当初为什么修改、在什么特定环境下触发的原始行为证据；② **一票否决全盘皆输**：一旦整套新技能在某个复杂综合任务里跑挂了，系统就会粗暴把整个修订版本全部回滚，导致其中明明改得很对的局部有效经验被一起冤枉丢弃。
- **机制突破**：提出“可重放证据驱动（Replayable Evidence）”的技能演进新范式：
  1. **证据卡片化打包**：把运行中遇到问题的上下文、报错和尝试过程封装成自包含的“可重放证据卡片（Evidence Cards）”，保留因果上下文；
  2. **局部靶向重放验证**：每次修改特定技能规则后，不急着跑全量宏观测试，而是直接调用证据卡片在原环境中进行单点再执行验证，谁对谁留；
  3. **跨周期暂存与渐进精炼**：局部验证通过的规则先放入临时池持续打磨，只有在后续多轮交互中被反复证实行之有效的规则，最终才被正式合并进主技能库；
  4. 在 6 个主流基座模型和 3 大交互环境中实测，极大降低了虚假规则的引入，使免模型微调的外部技能库能够稳健终身生长。
- **自进化意义**：让智能体的技能自演化从“盲目猜改、一挂就回滚”的脆弱逻辑，升级为了“带证据可重放、局部单独审查、渐进合入”的工业级知识沉淀体系。

## 2. GUI-HARVEST: Self-Improving GUI Agents through Evidence-Driven Harness Evolution
- **核心痛点**：图形界面（GUI）智能体（比如操控 Windows 或 Linux 桌面完成复杂任务）极难自演化。以往要想让它更聪明，只能重新收集大量屏幕录像花巨资微调大模型视觉头；而试图让它自动优化外部调度代码（Harness）时，又因为屏幕像素与操作意图脱节、操作偶发卡顿方差大，导致代码改动往往是治标不治本的乱试。
- **机制突破**：提出 **GUI-HARVEST** 框架，实现**大模型完全冻结前提下的 GUI 脚手架代码自主进化**：
  1. **前后截图视觉差对齐**：把智能体执行的动作与点击前后的真实屏幕截图精确对齐，把报错诊断死死锚定在具体的界面状态转移上；
  2. **同任务多趟运行联合对比**：同一道题跑几遍，通过成功与失败轨迹之间的像素与行为组内对照，精准定位到底哪一步点击造成了歧义或卡死；
  3. **预测性脚手架代码演化**：把跨任务高频共性失败归纳为代码补丁（如优化元素定位超时重试、状态变化判定逻辑），在真实执行前先预测行为改变，再在沙盒中闭环检验；
  4. 在权威计算机使用基准 OSWorld-Verified 上，推动 Qwen3-VL-32B 准确率**暴涨 +12.33 分**；演化出来的通用脚手架直接套给完全未参与训练的 GPT-5，在 WindowsAgentArena 上零样本提升 **+13.87 个百分点**。
- **自进化意义**：证明了让智能体变聪明不一定非要昂贵地重新训练大模型视觉权重，自演化出一套成熟、稳健的外挂系统交互脚手架代码，同样能实现跨模型的巨大飞跃。

## 3. EMHO: EMbodied Agent Harness Optimization via Experience Traces
- **核心痛点**：在机器人操作、物理环境移动等具身智能领域，底层的 VLA 动作模型通常计算代价高昂，无法在真实环境中频繁更新权重；而包裹在外层的控制规划流、重试策略和感知工具调用（Harness）全靠工程师手工拍脑袋写规则，一旦面对未见环境极易卡死或陷入死循环。
- **机制突破**：提出 **EMHO** 框架，开创“基于经验轨迹的具身脚手架代码自演化”：
  1. **端侧模型完全冻结**：让具身模型专心负责物理动作推理，由外部元优化器自主分析长程执行轨迹中的无效移动与感知盲区；
  2. **深层脚手架代码重塑**：不仅改动几句 Prompt，而是自主重写智能体评估自身进度的方式、视觉工具调用的触发时机、以及遇到物理阻碍时的回退策略；
  3. **EMHO-Merge 跨子任务无损合并**：针对单个共享脚手架既要管抓取又要管巡航导致的优化冲突，通过 Episode 级边际增益损失分析，实现自适应的分支融合；
  4. 在 EmbodiedBench 导航与操作任务上，全面提升 Qwen 9B 与 27B 模型的任务解决率，定性分析证实其彻底消除了机械臂与机器人的原地徘徊死循环。
- **自进化意义**：为物理机器人与虚拟具身系统在端侧算力受限的情况下，摆脱人工规则编写、依靠经验交互轨迹自主完成系统级自适应演化提供了全新路径。

## 4. VETTA: Coordinating Turn- and Token-Level Credit Assignment for Multi-Turn LLM Agents
- **核心痛点**：在多轮交互任务（如连续调用好几步工具订机票、修代码）中，环境只在最后给出“成功或失败”的极度稀疏奖励。现有的强化学习算法面临两难困境：① **Turn-level（轮次级）**：把某一轮的整段回复当成一个黑盒打分，根本分不清这轮回复里的格式套话与关键操作哪个立了功；② **Token-level（Token级）**：直接把最终奖励顺着自回归链往前平摊，在多轮几十步的长交互中方差大到无法收敛。
- **机制突破**：清华与中科大联合团队提出 **VETTA** 算法：
  1. **双头联合轻量 Critic**：在同一个参数量极小的 Critic 骨干网络上，同时挂载轮次级（Turn-level）与 Token 级（Token-level）两个专属价值头；
  2. **双重优势时序协同**：计算轮次级时间序列上的宏观 Advantage，再叠加轮内中心化的 Token 微观残差优势，两者联合驱动 PPO 策略更新，既掌握宏观步骤战局，又精准奖励微观关键 Token；
  3. **浅层 Critic 截断**：Critic 仅保留预训练模型前几层浅层 Transformer 块，在维持高质量状态估计的同时，大幅砍掉显存与反传开销；
  4. 在 ALFWorld 和 WebShop 上，推动 Qwen2.5-1.5B 成功率分别**狂涨 +37.5% 和 +22.3%**，Qwen2.5-7B 成功率逼近 95.5%。
- **自进化意义**：彻底打破了以往多轮交互智能体 RL 中“宏观轮次”与“微观动作”割裂评估的顽疾，以极小的 Critic 算力开销构建了超低方差、精准到位的多轮信用分配基石。

## 5. VeriFine: Scaling Verification for Self-Improvement in Embodied Reasoning
- **核心痛点**：大模型自进化存在一个著名的“验证瓶颈”：随着策略模型在自我迭代中越来越聪明，它暴露出的错误变得极其隐蔽、微观（涉及复杂物理反事实与空间遮挡）。如果用来评判它的判决器（Judge/Verifier）是固定不变的，那么当策略达到当前 Judge 的天花板时，自进化就会立刻停滞（陷入平台期），甚至因为 Judge 误判而学歪。
- **机制突破**：Stanford、NVIDIA、CMU 联合团队提出 **VeriFine** 框架：
  1. **策略改进内环（Policy Loop）**：利用当前量规判决器（Rubric Judge）诊断策略错误，动态编排自适应难度课程，优化策略模型；
  2. **判决器进化外环（Judge Loop）**：一旦发现策略提升遇到瓶颈，系统自动抓取最有争议的高难度失败样例，引入人机协同标定（Coactive Calibration），让人类指引帮助 Judge 快速升级对物理规律的认知深度；
  3. **判决器升级后再反哺策略**：更强大的新版 Judge 再去生成更苛刻的校验标准，驱动策略展开下一轮自我超越；
  4. 在端到端自动驾驶与复杂机器人决策中，策略与判决器呈现阶梯式持续同步自演化，彻底避免了单一判决器带来的性能天花板。
- **自进化意义**：实证揭示了自进化智能体最重要的定律之一——**“验证器能力必须伴随生成能力同步演化（Verification Scaling）”**，否则自进化必然走向停滞死局。

## 6. DAEDALUS: Bootstrapping Agent Memory from Self-Generated Tasks
- **核心痛点**：当智能体被扔进一个全新的未知软件环境（比如全新的 API、全新的操作系统工具）时，既没有人类写好的使用文档，也没有任何现成的练习题库和测试代码。智能体因为没有任何记忆，只能盲目试错，在最基本的语法和工具坑点上重复撞墙，失败率极高。
- **机制突破**：提出 **DAEDALUS** 框架，实现“无预设题目、无预设验证器”下的纯自主记忆自举：
  1. **探索者与求解器博弈（Explorer-Solver Synergy）**：
     - **Explorer（探索者）**：自主翻看环境接口，凭空出题，自己设计出具有一定难度但理应可解的练习任务；
     - **Solver（求解器）**：接题挑战；
  2. **严格的避坑经验准入机制**：从求解器的失败中提取操作经验与避坑准则（Heuristics），并且只有当求解器带着这条经验在后续多个新任务中**反复多次稳定通过测试**时，该经验才被允许正式入库；
  3. **提纯后的记忆直接服务真实任务**：生成的记忆库在面对实际未知任务时，直接作为前置系统上下文注入，在 AppWorld 和 $\tau^2$-bench 上将成功率拉升高达 **+15.9 个百分点**，pass^5 提升 **2.2 倍**，性能媲美直接用人类训练集监督。
- **自进化意义**：证明智能体完全可以在没有外部教师的前提下，通过“自主出题刁难自己、踩坑后提纯避坑指南、在后续任务中实战验证经验”的方式，完全凭空孵化出专业级操作记忆。

## 7. Self-Retrospection Distillation: Turning Post-hoc Experiences into Prior Foresight (SRD)
- **核心痛点**：在以 GRPO/RLVR 为代表的大模型强化学习中，有一个让所有人头疼的“冷启动死穴”：如果某个长程任务特别难，智能体采样出的这一组 Rollout **全部失败了（All-Failure Groups，全员 0 分）**，此时组内奖励完全没有方差，策略梯度瞬间归零！在小模型训练或高难度长程任务初期，往往有高达 **37%~98% 的分组是全灭状态**，导致模型根本无法起步自举。
- **机制突破**：提出“前瞻性学习（Prospective Learning）”与 **SRD** 算法：
  1. **后视特权重构（Privileged Hindsight）**：即使一条轨迹最终失败了，但跑完这一整条轨迹后，其实已经暴露了环境暗藏的机关、状态转移的分支以及陷阱所在；
  2. **把事后经验蒸馏为事前远见**：让模型在未真正执行动作之前，去对齐拥有完整轨迹上下文的“后视特权表征”，学会“提前预知前方的风险与转移态”；
  3. **推理期零开销**：该预知远见纯粹充当训练时的辅助正则化损失，实际部署测试时模型不用多吐任何字，零额外延迟；
  4. **全灭分组依然能产生强劲梯度**：即便全员 0 分，后视轨迹之间的状态转移差异依然能提供稠密的指导信号；在全负组高达 98% 的 2B 小模型极端场景中，传统 RLVR 彻底锁死在 **0.0%** 成功率，而 SRD 在相同采样预算下直接狂飙至 **60.6%**！
- **自进化意义**：彻底攻克了强化学习中“全负样本无法冷启动破局”的根本死穴，让智能体在极端困境下依然能从纯失败中提取营养，实现无痛自主爬坡。

## 8. How Much Evidence Should a Coding Agent's Self-Correction Carry? Adaptive Dirichlet Evidence for Self-Distillation (EESD)
- **核心痛点**：写代码的智能体会根据终端单元测试报错不断修改自己的代码（自纠错），并试图把改对的轨迹通过自蒸馏（Self-Distillation）吸收进自身权重。但以往算法忽视了一个致命问题：**这次纠错改对，到底是因为逻辑严密被充分验证了，还是纯凭运气蒙对了一个弱测试用例？** 如果对所有修正不管证据多少都给予相同权重微调，模型很快就会被轻率的巧合噪声带偏。
- **机制突破**：提出 **EESD**（有效证据自蒸馏）：
  1. **证据支持度与证据质量解耦**：将代码执行覆盖的测试范围与支撑该修正的“有效伪计数质量（Evidence Mass）”显式拆解；
  2. **狄利克雷后验不确定性惩罚**：利用狄利克雷共轭后验，在数学上严格推导出一个带不确定性惩罚的学习权重系数——证据越薄弱，权重衰减越剧烈；
  3. **稳定自蒸馏**：仅让那些拥有充分、密集执行证据支持的优质修正主导模型更新；在 DeepSeek 代码基座上仅需一轮更新，CodeARC 全测试 Pass@1 即从 15.0% 跃升至 **20.4%**，有效防止了代码表征的过拟合与退化。
- **自进化意义**：首次为代码智能体的“试错反思自更新”引入了严谨的贝叶斯不确定性赋权，确立了“多少证据配吃多大梯度”的科学准则。

## 9. Harness Engineering for Software Engineering via Modular Executable Dev-Primitives (HERMES)
- **核心痛点**：在包含数千个源文件的大型真实软件项目中，传统代码 Agent（如 SWE-agent）通常让单个模型在几万行的终端上下文里来回 `grep`、`cat`。交互越长，上下文就越臃肿爆炸，模型很快发生“语义漂移（Semantic Drift）”，忘了最初要做什么。全仓库迁移任务中仅有 5.4% 的 Agent 能够顺利跑完全程。
- **机制突破**：提出 **HERMES** 架构，将单体中心化 Agent 解构为“可执行开发原语（Dev-Primitives）”：
  1. **无源构件转化为主动原语**：把代码仓库里的模块、配置文件、测试脚本分别绑定一个轻量驻留 LLM，让代码构件变成拥有自我解释、自我修改能力的“自主节点”；
  2. **基于依赖图的动态局部激活**：报错后，仅沿着函数调用与依赖拓扑图激活关键关联原语，其余数千个组件完全沉睡，彻底根治上下文爆炸；
  3. **执行证据逆向归因诊断**：执行报错后，诊断机制精准把失败证据投影回特定原语，触发原位局部自修改循环；
  4. 四大软件基准上相比基线平均提分 **+12.4%**；搭载轻量 Qwen3-8B 作为原语节点时，表现逼近商业闭源 GPT-5.6 Sol，同时推理 Token 开销**暴减 26.2%**。
- **自进化意义**：将软件工程自进化从“单个全局 Agent 疲于奔命”的旧思路，彻底颠覆为“基于代码工程依赖图的分布式原语局部自治演化”，为工业级全仓库长程自进化指明了系统架构方向。

## 10. 关键理论、沙盒与安全基座精要 (Adjacent Foundations)

1. **DiVeR (VLA 决策关键验证器缩放)**：在具身机械臂控制中，传统验证器对所有时间步一视同仁，但多数步骤动作无关紧要。DiVeR 通过动作表示离散度锁定少数生死攸关的“决策关键状态”，将验证器训练权重重定向到关键步，以极低开销在实机上大幅提升测试期动作挑选成功率。
2. **When Tools Lie (当数学工具撒谎时)**：揭露大模型对外部 Python 计算工具盲目轻信的巨大脆弱性（注入细微错误结果后准确率由 100% 暴跌至 72.4%），实证对比强制反思策略与可选反思，证实“强制反思检验”能够 100% 恢复性能，为自进化外挂工具的防御提供了关键证据。
3. **HarnessSecurity-Bench (脚手架安全基准)**：实测 Claude Code、Codex CLI 等 6 大真实脚手架在 2,500 次运行下的安全机制，揭示开发者开启“自动批准”后恶意注入攻击成功率从 29.2% 飙升至 **95.6%**，为自进化系统的外部特权隔离划定了红线。
4. **Judged Useless, Queried Anyway (知无用而盲目查)**：发现智能体在内部明明已经推断出某次工具查询不会带来任何新信息，却在控制流上依然机械发起查询的“知行脱节”盲区，并提出主动停止决策干预机制，显著压缩了无效探索。
5. **MINDSET (能量驱动记忆 Schema 演进)**：打破了“长记忆就是反复用 LLM 摘要覆盖历史”的粗暴做法，利用最小能量状态转移管理不可变记忆版本，有效兼顾了历史记录保护与过时状态自适应。
6. **Agent in a Bottle (BOTTLED 智能体工作流灌装)**：探索智能体能否把自身通用能力“压缩灌装”为低成本的专用脚本或自蒸馏小模型。实测在商品匹配任务上成功将 Opus 5 的全流程推理成本**暴降 657 倍**，同时保留 82% 性能。
7. **Rethinking Cross-Tokenizer OPD (跨分词器在策略蒸馏)**：发现不同分词器之间的在策略蒸馏中，盲目追求大面积的 Span 监督反而会引入冲突的负面梯度，而在严格 1:1 单词对齐位置提取 Top-16 逆向 KL 蒸馏，不仅速度提升数倍且准确率更高。
8. **Beyond Corrected Memory (多智能体执行一致性 CAVERT)**：指出多智能体不仅要保证共享记忆“文字上没冲突”，更要保证状态使用与交接的“执行因果一致性”，构建了跨任务诊断与恢复框架。
9. **RL for Hierarchical Reasoning Rewards (层级推理奖励 Minimax 最优率证明)**：首次从数理统计理论上严谨证明：在策略（On-Policy）探索配合 Transformer Critic 能够在多步层级推理奖励下达到极小化极大的最优收敛速率，而离线采样存在无法逾越的对数衰减下界，从理论根本上闭环解释了在线 RLVR 探索的核心优势。
