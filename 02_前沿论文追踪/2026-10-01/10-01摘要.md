## 1. ScholarEvolve: Learning from Research: Toward Lifelong Agent Harness Evolution
   针对Harness的改进，论文提出的机制简单来说是，**自动爬取新论文转换为算子做演化**，从而实现终身进化能力。`[过去的做法是让大模型根据执行报错自己脑补修改 Harness 代码，容易出问题]`

1. **harness模块化**
   - 这篇论文把 Agent Harness 严格解耦为基础功能子域：Tools选择与组合、context管理、skills沉淀、memory维护和workflow控制。
2. **文献知识抽取与聚类**
   - 顾名思义，追踪顶级论文，对主题建模挖掘设计策略。
   - 元智能体将文献中的前沿设计模式实例化为代码级补丁，并在沙盒环境中并行测试不同模块策略的组合，最终沉淀出高胜率的 Harness 架构。
3. **终身终极演化 (Lifelong Evolution)**
   - 随时间推进，只要有新论文发布，系统就自动吸收转化为新算子，驱动harness做主动式、跨越式演化，彻底打破了单一智能体盲目试错的优化下界。

## 2. Turbo Harness: Instance-Adaptive Harness Optimization
   同样是针对 Harness 进化的。以往逻辑是寻找平均得分最高的harness直接用。问题就在于：现实世界的任务高度异构，针对不同的任务，表面上最好的harnes可能存在冗余流程或者有偏差的逻辑，进一步可能引导向错误。这篇论文就是针对harness处理异构任务做**动态路由**的。

1. **搜集旧经验**
   - 之前做harness全局搜索取最优时，搜索过程中探索过的海量失败/局部成功的分支代码，通常在最终选出最好版本后就被全部丢弃了。
   - Turbo Harness 把全局优化全过程产生的所有中间制品全部回收，提炼成一个高度结构化的**Structured Playbook**。
2. **实例级动态打补丁 (Instance-Adaptive Patches)**
   - 训练一个轻量级的 Harness Editor。在面对具体任务实例时，Editor 根据任务特征从 Playbook 中迅速检索经验，对全局 Harness 打上针对当前实例的微观补丁，实现对工作流等的微调等。
3. 本质上就是小模型作为Meta-Controller实现动态分配的逻辑

## 3. SCAPO: Semifactual Credit-Augmented Policy Optimization
   针对策略级信用分配（Credit Assignment）的。这论文针对的是 **GRPO 的连坐机制**。

1. 问题还是那个问题，整条轨迹中总有无关冗余token，由于轨迹的成功也被分配advantage，所以要找到真正的相关性做精准的credit assignment。
2. **半事实干预（Semifactual Intervention）探测敏感度**
   - **Semifactual Intervention**：这个的意思是，发生一些改变，但核心事实依然不变。例如替换同义词、调整句子顺序之类的，
   - 在保持题目核心语义与标准答案严格不变的前提下，对prompt做半事实干预然后输入。但是不重新采样，而是**轨迹固定**：
   `[轨迹依旧是原始的prompt自回归采样出来，随后将将这串已生成的 Token，强制喂入4个半事实Prompt下进行Teacher-Forcing前向计算，没有自回归生成开销]`
   - 观察固定推导轨迹在扰动前后的Token预测概率偏移量：
     - **偏移极小**：说明该 Token 是真正的逻辑推理核心步；
     - **剧烈偏移**：说明该 Token 严重依赖表层提示词的偶然巧合，是虚假相关的潜在病灶。
3. **因果稳定性门控**
   - SCAPO 在训练早期，依据半事实稳定性分数，强行扣减不稳定 Token 的 Advantage 权重，避免虚假相关性在早期被强化；而在推理阶段，直接抑制高漂移候选词解码。
4. 这些解决credit assignment的思路基本都一样，9-30的HDL注入的是后验事实查看token预测概率偏移，偏移大的是分歧点；10-1的SCAPO就是把扰动的 prompt注入观测偏移，偏移大的是无关点。也都用到了Teacher-Forcing前向计算减少开销。

## 4. Context Language Models (CLMs)
   针对context管理。目前的管理思路都是脚本那样的预设定的、规则化的。这篇论文的思路是**让大模型把自己的上下文当成一个文件，原生自主修改**

1. **把上下文视作原生可变文件 (Context as a Mutable File)**
   - 直接将模型的上下文映射为一个动态文本文件，智能体拥有对这个文件的无限制编辑权限。
2. **skill指导+RL**
   - 在 CLM 中，**文管理行为变成了模型自身 Action 的一部分。模型可以通过 Skill 优化循环自主进化出高效的上下文管理技能**
   - 甚至可以通过在线RL直接学习如何用最少的 Token 维持最高精度的长期推理记忆。
   - 结果上，CLM可以保持上下文文件保持在6K-8K Token的水平，实现极高的精炼，且prefill计算更快。
3. **缓存命中问题-Suffix Cache Reuse**
   - 传统的SGLang引擎由于**RoPE**位置编码无法复用后缀：
   - 假定上下文： [A (前缀)] [B (中间500行无用日志)] [C (后面重要的提炼事实)]，其中B经过文本Diff后变成[B']，[C]的绝对位置因此而变化。
   - `[SCR的逻辑是：新一轮上下文进来时，引擎先做极轻量的文本Diff，找出后缀块，调用算子按位置位移差直接乘上旋转矩阵修正位置，把修正位置后的[C]缓存，直接拼在新修改的[B']后面，这样只需要对[B']再做prefill，后面的[C]缓存命中]`
   - 之后再通过RL可以学到规范化的编辑习惯，最大化这个机制的作用。

## 5. PhantomEnvironments: Training LLM Agents in Fictional Worlds
   做强化学习与自进化的问题在于无法获取Verifiable Reward的真实长程交互环境，人类标注贵，大模型合成有幻觉。

1. **纯规则生成的“虚构世界”**
   - Cornell 与 Stanford 团队证明：**训练大模型长程检索推理智能体，根本不需要真实世界的语料或真实事实！**
   - 他们用纯符号逻辑规则构建了一整套“虚构世界”（PhantomEnvironments）：实体、关系、模板化文章、多跳问题全由纯确定性代码生成，零 LLM 参与、零边际成本、零数据泄露风险。
2. **纯逻辑能力的无损迁移与涌现缩放**
   - 智能体虽然在满是虚构概念的沙盒里用 RL 训练，但学到的是**多跳检索、逻辑推导、线索追踪的纯粹推理机制**；
   - 这种在虚构世界里磨练出来的能力，零样本直接迁移到真实世界复杂的多跳维基检索基准上，表现超越了在真实数据上微调的模型！
   - 模型在完全没有外部引导的情况下，自主涌现出了**根据题目复杂度线性扩展检索轮数与算力的 Test-Time Scaling 行为**。
3. **核心启示**：自进化智能体的演练场，不需要盲目追求现实世界语义的高保真，只要沙盒的逻辑拓扑深度与跳数（Hop Count）足够严密，智能体就能进化出通用的认知执行策略。

## 6. ComputerSD: Online Self-Distillation for Computer-Use Agents
针对 GUI 电脑操作智能体（Computer-Use Agents, CUA）在线自我进化的突破性工程。

1. **解决 GUI 智能体的中间信用黑洞**
   - CUA 面对的现实通常是几十步鼠标键盘操作后，只得到一个“成功/失败”的终局稀疏二值奖励。昨天浙大的 SCA 提出了几何距离场来缓解，而今天浙大与蚂蚁集团的这篇 ComputerSD 走的是**实时在线自蒸馏（Online Self-Distillation, OPSD）**。
2. **状态转移转为特权指导与价值评分**
   - 每一跳 GUI 动作执行后，由专门的轻量 GUI Analyzer 分析屏幕界面发生的实际状态跃迁，生成特权指导信息（Privileged Guidance）与单步价值分（Step-level Value Score）；
   - 用单步价值分动态调节 Token 级 OPSD 信号的强度，将实时环境反馈转化为细粒度的步级监督，并与轨迹级 GRPO 在完全异步框架下联合优化。
3. **核心启示**：多模态智能体演化必须充分榨取环境状态转移（State Transition）中的动态信息差，将其转化为步级价值信号。

## 7. EvoDuet: Bilevel Co-Evolution of Web Searching and Task Solving
自动化科研与解空间演化（Auto-Research）领域的突破。

1. **科研进化的死锁：搜索与解法的脱节**
   - 传统的演化搜索系统（如 FunSearch / OpenEvolve）在探索复杂前沿问题时，经常因为底层模型缺乏特定外部知识而卡死；如果简单挂一个搜索工具，智能体往往在几轮之后就开始反复检索相同的网页，搜索策略停滞。
2. **双层协同演化 (Bi-level Co-Evolution)**
   - **内层循环**：智能体自我诊断当前的“认知知识盲区（Knowledge Gap）”，专门针对未解决的瓶颈点动态演化搜索 Query，并依据文档对解法改进的潜在贡献对网页进行预测排序；
   - **外层循环**：从高质量文献中并行合成候选解法，将实际运行反馈写回记忆，用于指导后续的检索方向演化。
3. **核心启示**：信息获取机制（检索）与问题求解机制（推理执行）必须像两颗咬合的齿轮一样双向驱动、协同演进。

## 8. Understanding On-Policy Distillation: A Mechanistic Interpretability Perspective
最后这篇港大与剑桥的论文，回答了一个直击底层灵魂的机理问题：**在策略自蒸馏（OPD）到底在学生模型的神经网络内部改动了什么？**

1. **打破“知识灌输”的幻觉：OPD 不创造新特征**
   - 通过稀疏跨编码器（Sparse Crosscoders）和创新的 Swap Readout 技术追踪模型表征发现：**OPD 既没有为学生模型创造任何全新的特征，也没有把教师模型独有的内部表征传递给学生！**
   - 实际上，超过 98% 的高频特征激活率变化都在 20% 以内。
2. **本质机理：共享特征的重新加权 (Feature Reweighting)**
   - OPD 的本质并不是“知识传授”，而是“用法重构”——学生模型本来就在海量预训练中拥有了海量的隐式特征，OPD 只是让学生向教师学习**如何重新加权和激活双方早已共享的特征**，特别是放大了在关键决策 Token 处的特征响应；
   - 蒸馏前常用的 SFT 预热（Warm-up），其本质是在表层格式、推理风格和符号标记上提前做了一部分特征重权工作。
3. **核心启示**：在策略微调与自进化，实质上是在已有表征几何中“寻径”和“激活”，而不是从零造脑。只要基座具备潜在特征，通过轻量级精准信用分配，就能彻底激发其推理潜能。
