## 1. Learning from Research: Toward Lifelong Agent Harness Evolution (ScholarEvolve)
针对昨天人大那篇 Harness 自演化极限（指出简单反思搜索会陷入平台期）给出的破局方案。它回答了一个根本问题：**当大模型自己瞎折腾改不动代码脚手架时，该向谁学？**

1. **从自我反思到“外脑文献注入”**
   - 过去的做法（如 Meta Harness / Reflexion）是让大模型根据执行报错自己脑补修改 Harness 代码。这种“闭门造车”极易在狭窄的局部空间打转，而且面对复杂工具链报错时，大模型极其容易走向保守（比如疯狂加验证器导致正常调用被误杀）。
   - ScholarEvolve 的核心创新在于**把人类学术前沿（Research Papers）作为进化养料**：将 Harness 划分为工具、记忆、上下文、工作流等标准功能模块，持续抓取最新学术文献，利用主题聚类（Topic Modeling）提炼出各模块的差异化进阶策略，再自动合成代码补丁进行组合评测。
2. **终身终极演化 (Lifelong Evolution)**
   - 随时间推进，只要有新论文发布，系统就自动吸收转化为新算子，驱动脚手架做主动式、跨越式演化，彻底打破了单一智能体盲目试错的优化下界。
   - **核心启示**：自进化系统的脚手架更新，不能只靠“报错-反思”的被动反应式循环，必须建立“外源知识库驱动”的主动检索与策略合成闭环。

## 2. Turbo Harness: Instance-Adaptive Harness Optimization
同样是针对 Harness 演化的破局之作。昨天的论文证明了单一全局 Harness 存在逼近与泛化权衡，这篇论文直接指出了痛点：**“一刀切”的全局最优脚手架，在具体任务实例上往往是次优的甚至是有毒的。**

1. **废弃物再利用：从搜索副产物到 Playbook**
   - 之前做脚手架全局搜索时，搜索过程中探索过的海量失败/局部成功的分支代码，通常在最终选出最好版本后就被全部丢弃了。
   - Turbo Harness 把全局优化全过程产生的所有中间制品全部“废物回收”，提炼成一个高度结构化的**策略剧本库（Playbook）**。
2. **实例级动态打补丁 (Instance-Adaptive Patches)**
   - 训练一个轻量级的 Harness Editor。在面对具体任务实例时，Editor 根据任务特征从 Playbook 中迅速检索经验，对全局 Harness 打上针对当前实例的微观补丁（例如：面对回归Bug先调git log历史；面对复杂逻辑错误则先读控制流）。
   - **核心启示**：未来的智能体脚手架绝不是静态不变的代码外壳，而是“全局稳健骨架 + 针对任务实例动态注入的微补丁”。

## 3. Semifactual Credit-Augmented Policy Optimization (SCAPO)
继昨天 STAR-GRPO（防作弊）和 HDL（后验分歧定位）之后，在策略级信用分配（Credit Assignment）上的又一重磅突破。针对的是 **GRPO 的“连坐机制”与虚假相关性（Spurious Dependence）**。

1. **GRPO 的致命暗病：虚假特征被同等奖励**
   - GRPO 将整条轨迹的终局优势（Advantage）均匀赋给每一个 Token。如果 Prompt 里包含一些无关的冗余词或格式杂质，模型在侥幸做对题目时，这些无关 Token 也会被赋予同等的高正向奖励，导致模型逐渐“学会作弊”或对无关提示词过度敏感。
2. **半事实干预（Semifactual Intervention）探测敏感度**
   - 在保持题目核心语义与标准答案严格不变的前提下，对 Prompt 进行轻微的半事实扰动（如替换同义词、调整句序、变换非关键修饰）。
   - 观察固定推导轨迹在扰动前后的 Token 预测概率漂移量：
     - **漂移极小（稳定）**：说明该 Token 是真正的逻辑推理核心步；
     - **剧烈漂移（不稳定）**：说明该 Token 严重依赖表层提示词的偶然巧合，是虚假相关的潜在病灶。
3. **因果稳定性门控**
   - SCAPO 在训练早期，依据半事实稳定性分数，强行扣减不稳定 Token 的 Advantage 权重，避免虚假相关性在早期被强化；而在推理阶段，直接抑制高漂移候选词解码。
   - **串联认知**：9-28 的 SLCA 用片段切分，9-29 的 EAPO 用策略熵，9-30 的 HDL 用后验反思偏移、TGRL 用温度反差散度，今天的 SCAPO 则用**半事实因果扰动漂移**——本质全是在用极低算力剥离“侥幸生成的噪声 Token”，精准把梯度的刀刃落在关键决策点上。

## 4. Context Language Models (CLMs)
昨天讨论 CoEM 时探讨了长上下文暂存区与提交机制，而 Meta 和 UW 联合推出的 CLM 直接提出了一个更颠覆的范式：**为什么上下文管理必须由外部代码脚手架代劳？为什么不能让大模型把自己的上下文当成一个文件，原生自主修改？**

1. **把上下文视作原生可变文件 (Context as a Mutable File)**
   - 彻底打破了传统“历史对话线性追加”的死板设定。智能体拥有对自身上下文文件的无限制编辑权限（可以像在编辑器里一样定位插入、局部重写、整块删除冗余历史、提炼并更新全局状态）。
2. **从外挂启发式规则走向参数化/强化学习自演化**
   - 过去如何丢弃历史、如何滑动窗口，全是工程师写死在 Python 脚本里的硬编码逻辑；
   - 在 CLM 中，上下文管理行为变成了模型自身 Action 的一部分。模型可以通过 Skill 优化循环自主进化出高效的上下文管理技能，甚至可以通过在线强化学习（RL）直接学习“如何用最少的 Token 维持最高精度的长期推理记忆”。
3. **工程上的极致优化**：为了解决频繁修改上下文导致的 KV Cache 全面失效问题，设计了 Suffix Cache Reuse 机制，把服务器端算力开销大幅压缩。
4. **核心启示**：智能体走向极致自进化的终局，是把外围管理权逐步内化为原生感知与动作能力。

## 5. PhantomEnvironments: Training LLM Agents in Fictional Worlds
做强化学习与自进化，大家最大的痛点就是：**哪来那么多带准确 Verifiable Reward 的真实长程交互环境？人类标注贵得要死，大模型合成环境又容易幻觉甚至导致基准泄露。**

1. **纯规则生成的“虚构世界”**
   - Cornell 与 Stanford 团队证明：**训练大模型长程检索推理智能体，根本不需要真实世界的语料或真实事实！**
   - 他们用纯符号逻辑规则构建了一整套“虚构世界”（PhantomEnvironments）：实体、关系、模板化文章、多跳问题全由纯确定性代码生成，零 LLM 参与、零边际成本、零数据泄露风险。
2. **纯逻辑能力的无损迁移与涌现缩放**
   - 智能体虽然在满是虚构概念的沙盒里用 RL 训练，但学到的是**多跳检索、逻辑推导、线索追踪的纯粹推理机制**；
   - 这种在虚构世界里磨练出来的能力，零样本直接迁移到真实世界复杂的多跳维基检索基准上，表现甚至超越了在真实数据上微调的模型！
   - 更令人振奋的是，模型在完全没有外部引导的情况下，自主涌现出了**根据题目复杂度线性扩展检索轮数与算力的 Test-Time Scaling 行为**。
3. **核心启示**：自进化智能体的演练场，不需要盲目追求现实世界语义的高保真，只要沙盒的逻辑拓扑深度与跳数（Hop Count）足够严密，智能体就能进化出通用的认知执行策略。

## 6. ComputerSD: Online Self-Distillation for Computer-Use Agents
针对 GUI 电脑操作智能体（Computer-Use Agents, CUA）在线自我进化的突破性工程。

1. **解决 GUI 智能体的中间信用黑洞**
   - CUA 面对的现实通常是几十步鼠标键盘操作后，只得到一个“成功/失败”的终局稀疏二值奖励。昨天浙大的 SCA 提出了几何距离场来缓解，而今天浙大与蚂蚁集团的这篇 ComputerSD 走的是**实时在线自蒸馏（Online Self-Distillation, OPSD）**。
2. **状态转移转为特权指导与价值评分**
   - 每一跳 GUI 动作执行后，由专门的轻量 GUI Analyzer 分析屏幕界面发生的实际状态跃迁，生成特权指导信息（Privileged Guidance）与单步价值分（Step-level Value Score）；
   - 用单步价值分动态调节 Token 级 OPSD 信号的强度，将实时环境反馈转化为细粒度的步级监督，并与轨迹级 GRPO 在完全异步框架下联合优化。
3. **核心启示**：多模态智能体演化必须充分榨取环境状态转移（State Transition）中的动态信息差，将其转化为步级价值信号。

## 7. EvoDuet: Bilevel Co-Evolution of Web Searching and Task Solving
自动化科研与解空间演化（Auto-Research）领域的突破。

1. **科研进化的死锁：搜索与解法的脱节**
   - 传统的演化搜索系统（如 FunSearch / OpenEvolve）在探索复杂前沿问题时，经常因为底层模型缺乏特定外部知识而卡死；如果简单挂一个搜索工具，智能体往往在几轮之后就开始反复检索相同的网页，搜索策略停滞。
2. **双层协同演化 (Bi-level Co-Evolution)**
   - **内层循环**：智能体自我诊断当前的“认知知识盲区（Knowledge Gap）”，专门针对未解决的瓶颈点动态演化搜索 Query，并依据文档对解法改进的潜在贡献对网页进行预测排序；
   - **外层循环**：从高质量文献中并行合成候选解法，将实际运行反馈写回记忆，用于指导后续的检索方向演化。
3. **核心启示**：信息获取机制（检索）与问题求解机制（推理执行）必须像两颗咬合的齿轮一样双向驱动、协同演进。

## 8. Understanding On-Policy Distillation: A Mechanistic Interpretability Perspective
最后这篇港大与剑桥的论文，回答了一个直击底层灵魂的机理问题：**在策略自蒸馏（OPD）到底在学生模型的神经网络内部改动了什么？**

1. **打破“知识灌输”的幻觉：OPD 不创造新特征**
   - 通过稀疏跨编码器（Sparse Crosscoders）和创新的 Swap Readout 技术追踪模型表征发现：**OPD 既没有为学生模型创造任何全新的特征，也没有把教师模型独有的内部表征传递给学生！**
   - 实际上，超过 98% 的高频特征激活率变化都在 20% 以内。
2. **本质机理：共享特征的重新加权 (Feature Reweighting)**
   - OPD 的本质并不是“知识传授”，而是“用法重构”——学生模型本来就在海量预训练中拥有了海量的隐式特征，OPD 只是让学生向教师学习**如何重新加权和激活双方早已共享的特征**，特别是放大了在关键决策 Token 处的特征响应；
   - 蒸馏前常用的 SFT 预热（Warm-up），其本质是在表层格式、推理风格和符号标记上提前做了一部分特征重权工作。
3. **核心启示**：在策略微调与自进化，实质上是在已有表征几何中“寻径”和“激活”，而不是从零造脑。只要基座具备潜在特征，通过轻量级精准信用分配，就能彻底激发其推理潜能。
