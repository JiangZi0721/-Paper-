# 历史论文 PDF 归档目录 (Historical Paper PDFs Archive)

本目录用于沉淀与归档久远批次的论文原版 PDF 文献，以保持日常工作区轻量化并节约磁盘空间。

## 📦 当前归档包列表
- `september_2026_pdfs.zip`：2026 年 9 月份（2026-09-18 至 2026-09-30）全部 57 篇核心前沿论文 PDF 压缩包（约 210 MB）。
  - 内附完整相对路径结构（如 `2026-09-18/xxxx.pdf`），解压后可一键还原对应日期的原版 PDF。
  - 清单详情见 `september_2026_manifest.json`。

## 📌 说明
- 所有日常追踪 Markdown 研判简报（如 `2026-09-XX_自进化智能体论文精选.md`）与总索引 `00_论文追踪总索引.md` 均完好保存在对应文件夹中，未作任何删改；
- 每篇论文的 arXiv 官方正文链接、HF 讨论页与 GitHub 代码链接均永久有效；
- 依据 2026-10-08 工作区运维新规范，后续日常追踪不再本地下载原版 PDF，直接采用官方 arXiv 链接直达。
