## RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

    Harness相关。本篇论文讲给外层架构自进化的机制中加入正则化。
    Harness能放大agent端到端的能力，近年的Harness evolution利用LLM作为proposer，执行系统的recursive self-improvment，但是存在proposer测试用例逻辑泄露、过拟合、规则随演进变得冗长臃肿等问题。本项目的一个核心就是regularize，使自进Harness具备真正的跨分布泛化能力。
1. 正则化部署在两个组件：**Proposal-Side & Selection-Side**
    - **Proposal-Side Regularization**：
        - **①退火改动**：`[无约束的LLM倾向于同时修改多处逻辑，导致改动无法attribute且容易拟合noise]`，RRSI就施加L0退火风格的限制，演化初期允许大量改动，后期则缩减，只能进行单点微调；
        - **②信用分配**：`[传统搜索容易在已被证明失败的思路里重复犯错]`，RRSI维护完整的evolution日志，被拒收的方案直接作为强反例注入prompt，成功机制获得正向credit。  
        - **③熵激活**：`[近几轮搜索被困在经验噪声带内部时，判定为演化停滞（stall）]`，RRSI激活熵正则机制，将部分提案的预算分配给全局演化中未被碰过的冷门组件。
    - **Selection-Side**:
        - **①泄露审查**：进行评测前，独立的critic模型审查候选Diff，一旦发现有疑似试题泄露的，直接reject。
        - **②噪声容限**：RRSI事先统计噪声带，而每个新的候选想要被接纳，必须保证这个新候选的得分在噪声的波动之外，避免单纯的噪声波动被接受。
        - **③复杂度准入**：抑制token膨胀的L2类正则，RRSI将policy token的增量和性能得分增量挂钩，没带来显著性能跃升的规则直接reject。
        - **④组件剪枝**：L1类正则，物理删除多个窗口内未产生正向边际增益的prompt规则、tool等组件。
2. 从结果来看，RRSI进化出来的Harness具有强泛化能力。
3. 外层循环的自进化，也需要添加正则化机制。

## Harness-Zero: Harness Distillation via Agent-as-Harness
也是Harness，这篇论文加入的是distillation，将复杂**Harness诱导的高阶长程行为范式**内化至模型权重，部署时仅配置轻量Harness，高度还原复杂Harness的高阶行为规则。
1. 传统Harness的问题：`[agent必须动态路由，系统臃肿，延迟高，且无法适配升级后的模型；若共享Harness，小模型就无法驾驭复杂的通用工具`]
2. 为实现蒸馏，本论文引入Harnessing Agent，作为降维层。`[由于复杂harness的高级api无法被学生模型使用，只能学生自己构建]`，在学生模型向环境动作空间输出之前，Harnessing Agent就需要对学生的规划与动作进行在线干预，降成极简动作空间内的示范轨迹，才能进行参数微调.


## Jev-Mem: System-One-Controlled Agentic Memory for Efficient AI Agents
    当前的agent记忆系统普遍采用自回归大模型复杂记忆的分块、路由、更新等。延迟高还造成算力浪费。
`[Jev就是一个快速的决策器，具有快慢双系统，System-One负责糊类型判定、查询自适应路由、图遍历等快速决策，System-Two仅在面对极端复杂的推理与答案综合时，才被动唤醒重型 LLM，中间一层结构数据面用于维护记忆的时序因果与实体依赖。]`
1.  **System-One**控制器定义为一个有界概率预测接口：输入**结构化状态**与查询，单次前向传播直接输出离散概率，不产生自然语言.
2. **写记忆**：
    - Jev始终保留原始观测，不过早丢弃原文；
    - 做标签时，在四个维度重叠属性进行评分；
    - 建立关系时，直接混合检索筛选Top-k候选，通过system one判别四大维度的关系，只有超过门槛再插入有向边，**两个节点之间可以同时存在一条语义边和一条因果边**。
3. **读记忆**：
    - 给定query，预测深度需求和时效敏感度需求，针对特定需求做预算倾斜与压缩；
    - 在遍历的每一轮都评估证据集，证据足够或者边际递减直接截断；
    - 在新探索到的邻居节点中总和五维信号，有时序要求再叠加时间衰减因子进行评估

##  ACLArena: Agent Continue Learning in Multi-stage Post-training
`[MoE的Agent版本，相比MoE，专家更轻量、可终身自进化无干扰、能解决遗忘问题、切换更精准更快]`
    
    工业智能体必须在流水线的多个post training阶段依次吸收异质能力，但长期学习过程会遗忘前期的技能，且存在不同阶段能力互斥的问题。
1. 研究发现，不同任务的最优解在权重空间中的空间方向不同，经历越多的阶段训练，累计的几何位移越大，就越有可能忘记之前的，因此不可能通过单一权重兼容所有任务；此外，模型的退化和遗忘主要集中在6%的高熵token（关键动作）
2. 本论文横向评估Sequential RL(遗忘严重)、MMOPD、SDFT(偏科严重)和Model Merging(权重干扰严重)
3. **共性底座+隔离专家**：本研究提出的架构是**MLE(Mixture of Low-Rank Experts)**：新任务输入后，由router识别类型，激活对应LoRA，通用语言、指令格式等共享基座。
    - 基座来源于多领域的混合轨迹，经过SDFT学习通用交互行为，随后冻结权重。
    - 每个新领域都只分配轻量LoRA适配，独立在RL中进行决策精调。
    - 学习新领域就新增LoRA，物理隔离。
    - route不需要标签标注，能根据当前智能体交互环境的 Observable Context 提前进行切换。


## SkillSpec: Intent-Masked Specification Reasoning for Agent Skill Correctness
    Skill方面的。自进化的智能体会自己产生一些skill banks，针对这些技能的错误，linter等检查器只能检查语法问题，大模型又存在容错机制/思维定势之类的潜意识，可能掩盖一些冲突。本项目就研究如何自动化审查并形式化证明这些自演化出来的技能是否存在隐性缺陷与意图冲突。
1. SkillSpec将原子技能单元建模为霍尔三元组：前置条件、后置条件、副作用。据此构建两条独立的归约抽取路径：
    - **ExpectSpec**：从自然语言、skill的声明、context中推导，这个skill被认为应当履行的任务；
    - **FactSpec**：mask所有先验意图与注释，仅从程序来看，分析实现脚本带来的实际物理状态变化。
2. **Skill Graph**：分四个维度，针对不同输入context，施以不同程度意图遮蔽，从而推理实际和预期的偏差，在graph级进行交叉对比验证，使模型面对代码实现与文档规范之间的实质差异。
3. 静态对比出的偏差可能存在误报，SkillSpec还引入了沙盒验证，自动合成分化测试用例，配置监控探针，只有稳定复现出**违反规约**的行为，才被认定为确定性缺陷。
4. 只有通过了“ExpectSpec 与 FactSpec 等价性证明”且“副作用集严格闭包”的技能，才允许打入生产级技能库。
