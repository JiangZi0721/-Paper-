## 1. Memento 3: Model-Based Recursive Self-Improvement through Reflective Rulebooks
- **核心痛点**：在模型权重被冻结（Frozen LLM）的场景下，智能体进入未知环境时，纯语言反思容易产生多义性与因果幻觉，无法进行精确的动力学预测与长程规划。
- **机制突破**：UCL 团队提出 **Memento 3**，确立“自然语言规则书 $\to$ 可执行代码模型”的递归自演化闭环：
  1. **规则书编译代码**：维护反思规则书作为语义记忆，并自动将其编译为可运行的 Python 代码世界模型；
  2. **精确回放双验证门禁**：更新的代码必须满足规则书忠实度判断与历史状态单元格级精确复现（Cell-exact replay）；
  3. **表现震撼**：在 **ARC-AGI-3 上清空全部 25 个公开游戏关卡**（RHAE 达到 100.0），Atari Pong 对战中以 21:0 零封基线，且测试期零外部 LLM 调用。
- **自进化意义**：证明了递归自我提升（RSI）无需高昂的权重更新，通过“代码即模型”的自主重构与验证即可获得通用认知自演进能力。

## 2. AgentGarten: Code Worlds for Evolving Agents
- **核心痛点**：缺乏既具备程序化状态规则确定性、又具备物理世界高逼真视觉分布的可扩展环境，制约了智能体在开放世界中的持续自进化。
- **机制突破**：MirroS-Lab 团队提出 **AgentGarten** 框架：
  1. **代码世界解耦**：仿真后端维护世界状态与程序定义交互规则，共享神经渲染器负责生成逼真视觉；
  2. **对抗强迫微分回放（Adversarial Forcing）**：让历史 Prefilling 全程可微，未来预测损失反向更新历史状态编码；
  3. **跨代战术手册继承**：经验沉淀为结构化战术手册（Playbooks），后代智能体直接继承精炼，**仅用 4 轮交互即可达到传统强化学习数百万轮的收敛效果**。
- **自进化意义**：实现了“代码定义世界、经验沉淀手册”的环境与智能体协同演进范式。

## 3. ViSkill: Reinforcing VLM Agents with Evolving Visual-Native Skills
- **核心痛点**：传统技能库大多采用文本化转换，丢失了关键的空间几何与视觉拓扑信息，且技能更新与策略强化互相割裂。
- **机制突破**：浙江大学团队提出 **ViSkill** 视觉原生技能自强化框架：
  1. **复合视觉技能卡**：将高回报交互过程直接编码为视觉技能卡，保留完整的空间几何先验；
  2. **推理与奖励塑形双重引导**：检索出的技能卡既指导推理决策，又提供稠密中间奖励信号；
  3. **闭环反哺更新**：成功轨迹逆向蒸馏回技能库，形成“技能积累 $\leftrightarrow$ 策略优化”双向增强闭环，在 Sokoban 等任务上取得 0.91 的高胜率，收敛速度大幅领先 PPO。
- **自进化意义**：打通了多模态领域“视觉原生技能累积”与“强化学习策略梯度”的双向互促自进化通道。

## 4. SpatialOPSD: Self-Distilling Spatial Intelligence from Verified Coding Agent Traces
- **核心痛点**：空间代码智能体依赖外部工具导致推理延迟高、脆弱性强，直接用代码轨迹微调单体模型又容易发生严重的“特权捷径泄露”与死记硬背。
- **机制突破**：ATH-MaaS 团队提出 **SpatialOPSD** 在策略自蒸馏框架：
  1. **特权代码轨迹内化**：将经过验证的外部工具调用轨迹形式化为特权指导信息；
  2. **重复感知自蒸馏**：结合重复掩码与反似然正则化（Unlikelihood Regularization），根除特权作弊；
  3. 在空间推理与 OOD 迁移基准上全面击败 SFT 与 GRPO，实现 100% 免工具独立极速推理。
- **自进化意义**：为将外部复杂工具脚手架的能力完全内化到单体模型参数中提供了严谨的在策略蒸馏算法。

## 5. Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement
- **核心痛点**：具身机器人将大型神经网络（VLA）置于控制回路中，带来高延迟、黑盒不可控、显存开销大以及难以进行显式技能版本回滚的缺陷。
- **机制突破**：S-Lab 团队提出 **具身图灵机与纯代码即策略（COAP）**：
  1. **环境即纸带，代码即策略**：所有状态跟踪与动作逻辑完全由显式状态化 Python 代码库实现，控制回路无神经网络；
  2. **闭环代码 RSI**：后台代码智能体根据执行失败报错，持续自演化、修改、重构共享代码库；
  3. 在 RoboDojo 42 项双臂任务中，纯代码策略库斩获 **70.24% 的成功率**。
- **自进化意义**：开创了“智能体离线自演化变异控制代码，线上纯代码零延迟安全执行”的具身自演化新形态。

## 6. Mara Chain: Rethinking Failure as a Stepping Stone for AI System Auto-Evolution
- **核心痛点**：AI 系统自演化（编辑 Prompt、Harness、代码）在搜索过程中粗暴抛弃失败候选，导致系统频繁重蹈覆辙，Rollout 成本极其高昂。
- **机制突破**：蚂蚁集团团队提出 **Mara Chain** 失败链式精炼系统：
  1. **失败候选即垫脚石**：保留未通过门禁的候选，将前序累积的归因证据注入后续精炼链；
  2. **帕累托 Top-N 过滤**：限制精炼深度，基于帕累托前沿动态剪枝；
  3. 在 AppWorld 上以**减少 65.5% 的 Rollout 开销**实现超 GEPA 20.5% 的性能跨越，TerminalBench 2.1 提升超 20 个百分点。
- **自进化意义**：确立了自演化系统“失败经验全量因果利用”的高效搜索范式。

## 7. ReSPO: Reshaped Sequence Policy Optimization
- **核心痛点**：RLVR 跨步复用历史 Rollout 轨迹时，经典 PPO 截断机制压制低概率尾部的稀有正向长链推理，导致严重的“梯度饥饿”。
- **机制突破**：UCLA 团队提出 **ReSPO**：
  1. **双分支平滑序列核函数**：由 $\alpha$-散度变分目标与指数方差控制导出，替代机械截断；
  2. **正向样本保护**：确保在策略漂移下稀有正向长链推理依然获得有效梯度，同时平滑抑制负向样本方差；显著加速 Qwen3 模型强化学习早期收敛。
- **自进化意义**：为强化学习自我演化中的样本跨周期高效复用提供了底层数学支撑。

## 8. MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement
- **核心痛点**：万亿级 Token 全模态强化学习自演化极易遭遇奖励作弊（Reward Hacking）诱发的文本恶性膨胀与 MoE 路由崩溃。
- **机制突破**：小米团队披露 MiMo-V2.6 工业级自进化训练套件：
  1. **异步大规模流水线**：单步吞吐 1,568 样本、2.7-3.7B tokens，原生支持 1M 窗口；
  2. **分组多智能体裁判（Groupwise Agentic Grading）**：有效压制口惠式作弊，对冲长度膨胀；
  3. **冻结 MoE 路由与控制解耦**：保持底层策略平稳。
- **自进化意义**：树立了超大规模全模态模型强化学习自演化的工业级工程标杆。

## 9. Opera: A Verbal Critic Framework for Long-horizon Coding Agents
- **核心痛点**：传统批评者仅提供单点静态报错，无法追踪智能体是否真正根除隐患，容易引发“表面顺从但问题未解”。
- **机制突破**：Salesforce 团队提出 **Opera** 持久追踪批评者：
  1. **持久便签机制**：将每次修正作为便签追踪至问题根除；
  2. **在策略数据自沉淀**：Opera 引导的优质多轮轨迹微调 Qwen3.5-9B，在跨 Harness 切换时完全免除性能衰退。
- **自进化意义**：展示了高保真反思机制反哺在策略微调、抵御脚手架迁移退化的良性闭环。
