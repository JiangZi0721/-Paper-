Track, triage, verify, and document frontier academic papers from arXiv (cs.AI, cs.LG, cs.CL, cs.RO) and Hugging Face Daily Papers, strictly separating genuine closed-loop self-evolution from academic water-pouring, superficial wrappers, and isolated component tweaks.

## 🚨 CRITICAL VULNERABILITY PREVENTION: 彻底杜绝伪配额制与模板偏置漏洞

### 1. 绝对零配额铁律 (Zero Quota-Filling / Absolute Dynamic Count)
- **历史漏洞警示**：严禁受历史总索引中“精选 6 篇核心 + 2 篇关键前沿”模板的心理锚定（Template Anchoring Bias），严禁在潜意识中凑齐“6 篇核心 + 2~3 篇旁支”！
- **按需动态汇报**：当天有多少真正具备底层自进化突破的论文就据实收录几篇（可以有 1 篇、5 篇、12 篇，也可以是 0 篇）。
- **严禁削足适履**：
  - 绝不为了凑齐“6 篇”而把单点微调工具补丁（如 AutoCompact）或经院统计包装（如 CMP）硬抬为“核心”；
  - 绝不为了控制汇报篇幅而强行压制、隐瞒或折叠已经通过严苛筛选的真实核心突破。

### 2. 严禁大容积默认兜底 (No Greedy Default Fall-through / Anti-Adjacent Dumping)
- **历史漏洞警示**：严禁在分类代码中将未命中核心词的普通论文无脑 `else: category = adjacent_inspiration`！
- **精细化多级漏斗**：
  - 凡是缺乏环境交互闭环、无自演化更新准则、无确定性 Verifier 的常规单轮问答、纯文本微调、普通具身遥操作或经院统计计量包装，一律无情判定为 `not_recommended`；
  - `adjacent_inspiration` 仅限具备直接技术启发的外围关键基座（如真实可执行安全沙盒、奖励作弊评估基准、模型边界动作验证）。

### 3. 全景客观事实账本 (Objective Spectrum Integrity)
- 每次汇报时必须首先交代当前真实数据池底数（总候选篇数、初筛淘汰篇数、核心突破篇数、紧密周边篇数），保持学术透明。
